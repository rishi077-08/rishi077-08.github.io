# Rishi Raj — Professional Portfolio

Professional static portfolio for cybersecurity, penetration-testing learning,
security research, responsible disclosure and data science.

## Files

- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and footer year
- `assets/profile.jpg` — optional profile photo

## Important

Only publish information you are comfortable making public.
Never publish passwords, API keys, authentication tokens, session cookies,
private vulnerability evidence, or other sensitive information.
